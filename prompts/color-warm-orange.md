# 色调风格-可选

色调风格：暖橙 / 橙红。

主橙色使用 #FF4E26，珊瑚橙使用 #F86B42，浅珊瑚使用 #F27D6C。
正文使用深灰 #172033 或 #1F2933，次级文字使用 #5B6472。
浅暖底可使用 #FFF4ED / #FFF7F2，但只能作为信息承载，不要让页面整体发灰发淡。

主橙色应用于标题强调、粗线条、关键编号、核心结论框、流程主线、图形节点。
关键编号在白色或浅色底上优先使用 #FF4E26 实字；若使用橙色底，则文字必须使用 #172033 或清晰可读的高对比色。禁止 #FFF4ED、#FFF7F2 等浅色文字直接落在白底上。
页面不能只有浅橙、浅灰和细边框。
整体应商务、锐利、克制、有视觉力量，避免老旧系统控件风。

不要使用渐变。
不要用多段色块模拟渐变。
